# 架构

Tide 是一个**长期记忆运行时**，不是数字人外壳。它解决的问题是：
一个 Agent 怎么在很长的时间里记住一个人，并且记得住、忘得掉、不串门。

## 一句话

**原文是唯一真相，其余全是派生。**

事实、事件、概要、索引、交接、日记都可以从原文重建；原文只追加，不覆盖。

## 八条不变量

1. **原文唯一真相**：`*-私聊.md` / `*-群-*.md` 只追加；派生文件可重建。
2. **一个大脑，多条通道**：每条原文带通道标记（`[cli]` / `[qq]` / …），通道只决定措辞和可达性。
3. **隐私在装配层裁剪**：群里物理上拿不到私聊原文/事实/日记，不靠提示词求模型别说。
4. **四条节奏**：秒（原文）/ 分钟（状态）/ 天（日批）/ 月（遗忘与稳定度）。
5. **状态不是记忆**：情绪、好感、体质只进 `state/`，绝不写事实表。
6. **水位只在整批成功后推进**：日批前有快照；失败退避重试；apply 幂等。
7. **模型可选**：没 key / 断网时，离线占位 + 规则整理器仍把记忆链路跑完。
8. **单写者**：一个数据目录同时只能有一个进程写。

## 分层

```
        CLI / HTTP                 （adapters）
             │
             ▼
  Service · Assembler · Memory · Batch · Retrieve · Forget · State   （core）
             │
             ▼
        文件和索引                  （storage）

  plugins：QQ / 宠物 / 语音 / 画画 / 摄像头（可选，不进核心）
```

依赖规则：

- `tidecore.core` 只允许标准库和 `tidecore.core`；
- `tidecore.adapters` 可以依赖 core；
- `tidecore.plugins` 可以依赖 core；
- core 永远不 import adapters/plugins。

CI 用 import-linter 钉死这条规则。

## 一轮对话

1. 通道送来 `Turn(sender, text, channel, at)`。
2. 身份闸门判定 `owner` / `member` / `stranger`。
3. 原文追加到当天文件（只追加）。
4. 装配提示词：
   - 稳定 head：人设 + 核心 + 边界 + 死规矩；
   - thread：最近对话；
   - 动态 tail：检索到的事实/事件/原话 + 当前状态 + 时间。
5. 模型回复（或离线占位）。
6. 抽出 `<cmd>` 动作，交给插件执行。
7. 她的话写回原文和 outbox / 通道。

## 一次日批

1. 过了配置的钟点，检查水位。
2. 快照整个记忆目录。
3. 模型抽取事实/事件/概要；离线退回规则。
4. 幂等 apply：关闭过时事实、合并新事实、写概要/日记/交接、重建索引。
5. 跑体检，写状态。
6. **全部成功才推进水位**；否则安排重试。

## 四条节奏

| 速度 | 谁写 | 落在哪 |
|---|---|---|
| 秒 | 代码 | 原文追加（带通道标记） |
| 分钟 | 心跳 | 此刻、今日行动、outbox |
| 天 | 模型/规则 | 事实、事件、关系、日记、核心、索引 |
| 月 | 代码（检索时现算） | 遗忘：召回加固、淡出注入、归档不删 |

## 目录

```
data/memory/
├─ 2026-11-03-私聊.md       原文
├─ 2026-11-03-群-<id>.md    群原文
├─ 事实.md / 事件.md / 关系.md / 经历.md
├─ 核心/我.md  核心/<主人>.md
├─ 我/此刻.md  我/日记/…
├─ 人/<昵称>.md
├─ _状态.md  _审计/写入.jsonl
├─ _历史/（日批前快照）
└─ _索引.db（可重建）
```

派生文件可以删、可以重建；原文不能删。

## 边界

不包含：GUI、QQ 协议端、语音合成、唱歌、画画、摄像头、Live2D。
这些依赖第三方运行时或不可再分发资产，放在独立插件仓库。

## 扩展点

`tidecore.core.hooks` 是已实现的真实接口：

```python
hooks.before_turn(fn)   # fn(turn)，可改 turn.text
hooks.after_reply(fn)  # fn(turn, result)
```

一个插件抛异常不会打断对话；注册顺序就是调用顺序。
`action` / `heartbeat` / `prompt_block` 是 P2 计划，不在 0.2.0 里。
